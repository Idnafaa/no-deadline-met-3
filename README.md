A tiny program that writes one single-line joke excusing a missed deadline (114 characters, one line, nothing else) to entry.txt for make.fun's "One Line, No Deadline Met" bounty.

## Run it

```sh
python3 main.py
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
